# Weather App

A real-time weather app built with React and Vite using the OpenWeatherMap API.

## Features
- Search any city worldwide
- Display current temperature, weather condition, humidity, wind speed, and feels-like temperature
- Clean modern UI

## Setup
1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` file based on `.env.example` and add your OpenWeatherMap API key:
   ```bash
   cp .env.example .env
   ```
4. Start the app:
   ```bash
   npm run dev
   ```

## API Key
Get your free API key here:
https://openweathermap.org/api

## Build for production
```bash
npm run build
```
